# Alerta Andina

**Aplicación web (PWA) gratuita y sin registro para seguir los sismos de Perú y la región andina en tiempo real, y preparar un plan de emergencia.**

👉 **[Ver la app publicada](https://alerta-andina.netlify.app)**

Trabajo Final de Posgrado · Desarrollo FrontEnd para Diseñadores · Shifta · Elisava (2026)

## Qué hace

- **Sismos en tiempo real** de Perú, la región andina y el mundo, con mapa interactivo.
- **Anillo de magnitud**: el color dice el nivel (leve, moderado, alto, crítico) de un vistazo.
- **Actividad en la zona**: posibles réplicas en 100 km y reproducción de los últimos 30 días.
- **Mi Plan**: contactos, mochila de emergencia con vencimientos y dirección.
- **Modo emergencia (SOS)**: silbato y voz que funcionan sin internet.
- Sin cuenta ni publicidad: todo se guarda en el propio dispositivo.

## Tecnologías

HTML · CSS (tokens, Grid, mobile-first) · JavaScript · Vue 3 + Vite · Leaflet + OpenStreetMap · APIs de USGS y EMSC · Web Audio · Speech Synthesis · PWA · Netlify

## Ejecutarla en local

El código está en la carpeta `alerta-andina-vue`:

    cd alerta-andina-vue
    npm install
    npm run dev
